A Census Management System developed in C# using Visual Studio. The system is designed to manage and organize census-related information efficiently through a user-friendly application.

Features:
Add and manage census records,
Store personal and demographic information,
Search and view census records,
Update existing records,
Delete records,
User-friendly interface,
Organized data management,
Built using C# and Visual Studio,

Technologies Used:
C#, .NET, Visual Studio, SQL Server
